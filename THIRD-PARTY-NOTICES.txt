# Third-party software

OfferWeave Free relies on WordPress-provided APIs, libraries, translations and the media library. No Freemius SDK, remote checkout assets or SDK translation catalogs are included. Its optional purchase links open the external Freemius checkout in the user's browser.

OfferWeave is distributed under GPL-3.0-only; see LICENSE. Earlier OfferWeave code was available under GPL-2.0-or-later. Development tools are not included in the installation ZIP.
